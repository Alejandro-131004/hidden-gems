Leitura

Resposta honesta: não é conclusivo. A tendência vai no sentido certo mas não é estatisticamente significativa, e mudar de clube não é o mesmo que subir de nível. Serve como sinal de que o índice não é ruído puro — não como validação.

Como foi feito

O caminho até aqui

Os dados vêm de exportações manuais do Wyscout, organizadas em 82 pastas de liga segundo o mapa de prioridades. Estão recolhidas 75 ligas e 39 650 jogadores, com verificação automática de contagem por liga. Cinco ligas continuam por fechar: duas não têm época definida no Wyscout, duas não existem lá, uma está por confirmar.

Esta versão usa as 75 ligas recolhidas, não apenas um punhado escolhido por serem parecidas — é isso que o passo de força de liga, abaixo, torna possível.

O cálculo, em sete passos

1. Só entram jogadores com pelo menos 600 minutos numa posição conhecida.
2. As métricas de cada posição são convertidas em percentil, mas só dentro da mesma liga e posição — a qualidade da liga não entra ainda aqui.
3. Ligas com poucos jogadores numa posição são comparadas com um grupo maior de ligas de nível parecido, para o percentil não assentar em 3 ou 4 jogadores.
4. Uma percentagem construída sobre poucas tentativas (100% em 1 cruzamento) é puxada para a média até haver tentativas suficientes.
5. O resultado é puxado para a média proporcionalmente aos minutos jogados — meia época conta como indício, não como prova.
6. Só agora entra a força da liga, como correção final, para tornar ligas diferentes comparáveis entre si.
7. A idade nunca entra na pontuação — fica sempre numa coluna à parte, só para consulta.

Os pesos das métricas dentro de cada posição são iguais entre si. Não foram afinados, de propósito: afinar pesos sem um alvo de confiança para os validar seria inventar.

O que precisamos de decidir convosco

  • A força de cada liga ainda é uma primeira estimativa. Vem do ranking de associações da UEFA para a Europa, e do valor de mercado mediano para o resto do mundo — nenhuma das duas fontes é perfeita. Onde vocês têm conhecimento direto de nível entre ligas, essa correção pode ser afinada à mão.
  • Um índice ou vários perfis por posição? Nos radares vê-se que jogadores com índice parecido têm perfis de jogo diferentes — um número só apaga a especialização. Faz sentido dividir cada posição em perfis, e nesse caso quais são os perfis que vos interessam?
  • O que significa "subvalorizado" para vocês? Uma fração relevante dos jogadores da base não tem valor de mercado no Wyscout, e a falta é maior precisamente nas ligas mais obscuras. Ou seja: onde é mais provável haver um achado, é também onde há menos preço para comparar. Ou o critério passa a ser só desempenho, ou é preciso outra fonte de valores.
  • Que corte de elegibilidade? Usa-se aqui até 25 anos com 600+ minutos, mas o objetivo do filtro em si não tem tecto de idade — jogadores mais velhos com potencial também contam, o corte de idade é só uma escolha desta demo para caber numa tabela. Faz sentido a empresa ver a lista sem esse corte também?
  • Uma época chega? Só temos 2025-2026 recolhida em profundidade. Sem duas épocas não se mede evolução — e potencial é, no fundo, uma trajetória. Vale a pena recolher 2024-2025 para as ligas prioritárias, para permitir um teste retrospetivo real?
